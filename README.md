Hands-on cybersecurity learning portfolio covering web application security, network analysis, operating systems, and defensive practices.

## Labs

| Lab | Topic | Status |
| --- | --- | --- |
| [DVWA Brute Force Lab](labs/dvwa-brute-force/README.md) | Web authentication, HTTP request analysis, and login defenses | Report published |

## Method

Concept → Lab → Analysis → Troubleshooting → Documentation.

Only owned or explicitly authorized systems are used. Observations are separated from hypotheses and unverified tests.

## Evidence handling

Before committing screenshots or packet captures, redact active session tokens, authentication headers, passwords, API keys, and identifying information. Keep original evidence private. Never assume virtualization alone provides network isolation.
